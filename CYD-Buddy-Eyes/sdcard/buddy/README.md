# CYD Buddy SD Files

The firmware uses `/cydbuddy/` on the CYD SD card.

Current expected file:

```text
/cydbuddy/phrases.csv
```

CSV format:

```text
mood,phrase,source
"curious","I am awake, mildly judgmental, and waiting for something interesting.","user"
```

This repository folder is only a reference for the SD-card layout. The live file is created and updated by the CYD firmware on the physical SD card.
